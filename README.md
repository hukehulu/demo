变送器是工业自动化领域的重要设备，可将传感器检测的物理量（如温度、压力等）转换为标准电信号进行传输。数字式变送器则将模拟信号转换为数字信号，便于远程监控。本设计旨在理解单片机在工业测控中的基本应用。

使用Proteus仿真软件，基于STM32F407系列单片机设计一个简易数字式温度变送器系统。具体功能如下：
1. CPU为STM32F407系列单片机；
2. 使用一个电位器模拟温度传感器输出，电压范围0.5V～3.0V，线性对应温度值0.0℃～100.0℃；
3. 采用四位数码管动态显示当前温度值，格式如“25.6”（显示小数点后一位）；
4. 三个LED灯（系统运行指示灯（闪烁黄灯），上限报警指示灯（点亮红灯）、下限报警指示灯（点亮绿灯））；
5. 三个按键（模式键——切换显示内容，加、减键修改报警上限）；
注：下限阈值固定为20.0℃，无需修改；
6. 实现上下位机通信。
